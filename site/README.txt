SJGAM M66 / M68 — standalone website

Open index.html in a modern browser. Images, styles and scripts are embedded:
the page works offline. Only external source links need internet access.

The supplied manufacturer page identifies M66, not M68; SJGAM's site lists no
M68 at all. The M66 specifications on the page are manufacturer-listed, not
independently benchmarked.

The "Inside the M68" section is the exception: it is first-hand, read from the
SD card of a retail M68 (build M68 V1.0.0, 22 January 2026). It establishes
that the M68 is a different platform from the M66 the manufacturer documents —
a Rockchip Cortex-A7 running Buildroot with a custom MiniGUI launcher, not an
Amlogic-class part running EmuELEC. One unit only; other batches may differ.
The underlying teardown, notes and tooling are in the parent repository.

Package contents: standalone HTML, original manufacturer image assets, source
page snapshot and this README. The source snapshot is a research record; the
finished HTML is the website to open.

Research date: 17 October 2026. Firmware section added from the teardown of the
January 2026 build.
